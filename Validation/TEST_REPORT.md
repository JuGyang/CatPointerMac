## 本版设置体验

- “指针尺寸”为五档滑杆：小 80%、偏小 90%、标准 100%、偏大 110%、
  大 120%；“小猫动作速度”为慢、适中、快、极致四档，不显示 FPS、性能模式
  或省电术语。
- 拖动时右侧值、刻度高亮、状态文字和触觉反馈立即跟随；松手后的下一次主循环
  只提交最终档位。轨道点击、同档松手和拖回原档不会产生多余注册。
- 设置提交后开关、状态和菜单勾选立即显示目标值，不再先跳回旧值。真正的系统
  注册、读回验证成功后才保存；失败时恢复上一个可用设置。
- 左右/上下方向键每次严格移动一档，长按按键以 75 ms 合并最后一次输入；
  VoiceOver 的增减动作、当前值描述和值变更通知保持一致，且不再重复播报。
- 顶部使用原生开关，文字也可点击；“恢复默认”只在需要时启用。窗口支持
  Esc 关闭、记住上次位置、清楚的焦点顺序，以及针对暂停/启用状态动态变化的
  说明。
- 修复 AppKit 旧指针缓存覆盖新设置的问题：重新注册后按当前 Arrow / 文字输入
  指针角色立即刷新，并在下一次主循环再次确认，不注入鼠标事件。
- 暂停状态下调整设置只保存配置，并明确显示“设置将在启用后生效”；重新启用
  后一次应用。
- “检查是否正常”显示内联忙碌状态并暂时禁用设置控件；通过时在设置页内显示
  结果，不再额外弹出成功对话框。待应用设置失败时不会继续检查、覆盖原错误。
- 快速调节后立刻暂停或退出时，最后已提交的选择会先保存/应用，不会被 75 ms
  合并窗口丢弃。

## 速度、响应与资源

四档均注册 24 帧：

| 档位 | 单帧时长 | 完整循环 |
|---|---:|---:|
| 慢速 | Arrow 178.750 ms；文字输入 192.500 ms | 4.29 s / 4.62 s |
| 适中 | 83.333 ms | 2.00 s |
| 快速 | 50.000 ms | 1.20 s |
| 极致（默认） | 33.333 ms | 0.80 s |

最终应用内自检会先准备固定的 5 尺寸 × 2 角色缓存，再走与界面相同的
WindowServer 重新注册路径逐档计时。连续三轮结果：

- 5 档尺寸单次应用最慢：35.14 ms。
- 4 档速度单次应用最慢：26.81 ms。
- 三轮全部 `passed: true`，设置后立即读回正确尺寸、热点、24 帧和时长。

从最终 ZIP 解压到全新目录后的独立自检同样通过，最慢尺寸切换 34.46 ms，
最慢速度切换 31.69 ms。AddressSanitizer / UndefinedBehaviorSanitizer 构建下
完整系统自检通过，最慢尺寸 / 速度切换为 56.79 / 51.56 ms，未报告内存或
未定义行为错误。

最终包启动并完成五档预热后的空闲状态：

- 完成预热后连续 6 次 CPU 采样：均为 0.0%。
- 设置窗口关闭时 physical footprint 约 32 MiB，峰值约 34 MiB；设置窗口打开
  时约 42 MiB，峰值约 42 MiB。
- CG raster：约 3.83 MiB；其余固定胶片主要计入应用本地缓存。

- 固定图像缓存只接受五个公开尺寸，最多 10 项；其他调用尺寸不进入常驻缓存。
- 动画由 WindowServer 播放，应用没有逐帧定时器、鼠标监听、输入钩子或覆盖
  在指针上方的悬浮窗。

## 功能与恢复测试

- Arrow 与文字输入指针的 5 档尺寸、4 档速度、热点和 Retina 表示全部通过。
- 自检强制走文字输入角色保持路径，完成一次真实重新注册，确认角色记录、文字
  指针快照与 WindowServer 激活请求均成功；此项不依赖后台进程无法控制的前台
  文字区域。
- 在 TextEdit 中完成点击定位、拖动选择和上下滚动，操作不受猫标影响。
- 暂停后 WindowServer 立即恢复原生单帧指针；暂停时改为 90% / 快速，
  重新启用后读回 90%、24 帧、50 ms。
- 旧版任意尺寸会迁移到最近的五档值；旧速度值
  `original / efficient / balanced / high` 分别迁移为
  慢速 / 适中 / 快速 / 极致。
- 正常退出、`SIGTERM`、`SIGINT` 均恢复原指针；崩溃遗留备份可由下一次启动
  或 `--restore` 恢复。
- 单实例锁、重复应用、系统唤醒、会话恢复和显示器变化后的合并重应用通过。
- 设置失败时仅在系统注册验证成功后写入偏好；失败回滚会报告当前真实状态。
